# BD Caling V1.0.0

**Release type:** Initial release  
**Version:** 1.0.0

## Overview

The first BD Caling release introduces a Flutter app prototype for browsing service ideas and categories for events and personal occasions.

## What's included

- Home screen with an auto-playing featured banner carousel
- Browsable service categories: Aesthetics, Cuisine & Pastry, and Fashions
- Occasion shortcuts for Wedding, Birthday, and Baby Shower
- Sample service cards displaying titles, prices, and ratings
- Login screen UI

## Notes

- Listings use sample data and images loaded from remote URLs.
- Authentication, search, and listing actions are not connected to backend services.
